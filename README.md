# GMM THEE V — Fan-Made Website 💙

A creative fan-made website inspired by the Thai BL series **Me and Thee**.

Imagine GMMTV under new management, with Khun Thee as the chairman! This website brings that fictional entertainment company to life with a modern blue-and-white design and a little corporate comedy.

## ✨ Features

- Modern blue-and-white website theme.
- Responsive design for desktop and mobile.
- Fictional chairman's welcome message.
- Company departments and announcements.
- Searchable artist directory.
- Alphabetical artist filters.
- Mobile-friendly navigation.
- Interactive elements using JavaScript.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 How to View

1. Download the project files.
2. Keep all files in the same folder.
3. Open `index.html` in your browser.

No installation required!

## 💙 About This Project

This website is a fan-made creative concept inspired by Khun Thee and the fictional GMM THEE V company from *Me and Thee*.
